## 实现清单

### AssistCardView：流式卡片

`app/src/main/java/com/dshgojava/assist/ui/AssistCardView.java`

- 原生 `FrameLayout` 卡片，标题、状态行、骨架屏、可滚动/可选中结果文本、追问输入区与底部动作条。
- `render(...)` 可从模型回调线程调用：内部 `post()` 到主线程，并把流式刷新合并为最多每 80 ms 一次；终止状态（DONE / FAILED / CANCELLED）立即刷新。
- 首字前显示骨架条，不伪造占位答案；GATHERING / THINKING 显示明确状态文案。
- 底部动作：复制、分享、追问、重试（仅失败且宿主提供能力时）、停止（仅运行中）、关闭。
- 顶部拖动条支持下滑关闭：达到 72 dp 或向下快速滑动时淡出并通知窗口层移除；否则回弹。
- 卡片优先使用 `WindowInsets.Type.ime()`；API 26–29 使用旧式 `getSystemWindowInsetBottom()` 兜底，避免低版本静默失去 IME 处理。
- `ACTION_OUTSIDE` 与返回键处理：输入条打开时先收起输入条，否则关闭卡片。

`app/src/main/java/com/dshgojava/assist/ui/CardUiState.java`

- 纯逻辑投影：把 `AssistResult` 映射为骨架/文本/状态/复制分享/追问/停止/重试可见性。
- 追问按钮只在 `DONE`、结果非空且尚未使用追问时可用；使用后显示“该结果已使用过唯一一次追问”。

`app/src/main/java/com/dshgojava/assist/ui/CardPlacement.java`、`CardIme.java`

- 纯逻辑计算卡片宽度、同侧滑入位置、safe-area 限制、拖拽关闭阈值与 IME 抬升位置。
- `CardIme` 缓存最后一次非零 IME 高度，忽略重排期间“可见但高度为 0”的中间态。

### AssistAskBar：追问输入

`app/src/main/java/com/dshgojava/assist/ui/AssistAskBar.java`

- 原生 `LinearLayout`：单行 `EditText`、发送、取消、状态文案；上限 4000 字符。
- 空白内容不发送并显示明确提示；发送中禁用输入与发送键。
- 复用参考实现的交互思路（IME action、发送/取消、返回键），但按本仓库资源与包结构重写，未复制 pet 专属资源或 `AppStrings`。

### AssistCardLayer：卡片窗口与追问生命周期

`app/src/main/java/com/dshgojava/assist/ui/AssistCardLayer.java`

- 使用 `TYPE_APPLICATION_OVERLAY` 窗口；宽度为 safe area 宽度减去两侧各 16 dp（即设计要求的屏宽 - 32 dp），高度限制在 260–560 dp 且不超过可用区域。
- 从悬浮球所在侧滑入；窗口初始放在屏幕外，通过 `updateViewLayout` 动画到最终 x。
- 窗口标志：`FLAG_NOT_FOCUSABLE | FLAG_NOT_TOUCH_MODAL | FLAG_LAYOUT_IN_SCREEN | FLAG_LAYOUT_NO_LIMITS | FLAG_WATCH_OUTSIDE_TOUCH`；追问时临时去掉 `FLAG_NOT_FOCUSABLE`，并设置 `SOFT_INPUT_ADJUST_NOTHING`。
- 收到 IME 高度时同时上移并按需临时缩短卡片，保证输入条位于键盘上方；关闭追问后恢复原高度与位置。旋转时先收起输入条再重排。
- 复制写入系统剪贴板并提示“已复制”；分享发起 `ACTION_SEND` + `text/plain` 选择器；失败均给出明确提示，不写正文日志。
- 关闭、窗口异常、服务销毁都会取消订阅、取消追问、关闭运行并移除窗口，避免迟到回调覆盖状态。

### 一轮追问与模型重试

`app/src/main/java/com/dshgojava/assist/AssistFollowUp.java`

- 每次卡片创建独立会话；`begin(...)` 只允许成功发起一轮，之后再次调用明确返回“本轮仅支持一次追问”。
- 追问提示词包含上一轮任务、上一轮结果和本次追问；不再取料、不重新截图，符合设计 §8.7 的无状态 P0 模型通道。
- 状态：THINKING → STREAMING → DONE / FAILED / CANCELLED；空响应、未配置模型、模型异常均有明确文案。
- 失败后 `retry()` 复用同一轮问题重试模型，不增加第二轮；取消后迟到的 delta/完成回调被忽略。

`app/src/main/java/com/dshgojava/assist/ModelRetry.java`

- 新增可选运行能力接口；`DefaultAssistRunner.Run` 实现它，只保存最近一次模型 prompt/images。
- 模型失败后可从卡片重试，不重新取料；取料失败、前置失败不具备模型重试能力。
- 该接口是卡片重试所需的内部扩展，不改变设计文档中的 `AssistRunner` / `AssistRun` 方法签名。

### 服务接线

`app/src/main/java/com/dshgojava/assist/service/AssistOverlayService.java`

- 创建 `ScreenSource`、`ClipSource`、`ImageSource` 并装配 `DefaultAssistRunner`，同时创建 `AssistCardLayer`。
- 任务选择后启动 run、展示卡片，并把 `ModelRetry` 能力传给卡片。
- 旋转时重排球与卡片；销毁/停止时移除卡片并取消运行。
- 当前服务仍使用 `NullModelChannel`，因此任务入口继续灰显“未连接，点此去连接”，不会伪造卡片结果；QA07/QA09 接入真实模型后即可走同一卡片链路。

## 与设计文档的差异

1. **初始模型失败重试**：设计 §9 要求“仅重试模型调用，不重新取料”。为满足该要求，新增可选的 `ModelRetry` 接口并在 `DefaultAssistRunner` 内部保存最近一次 prompt/images；`AssistRunner` 与 `AssistRun` 的既有签名未改。取料失败不会显示重试。
2. **追问上下文**：按设计 §8.7，只把上一轮结果与追问并入新请求，不重新取料，也不重新上传原图。图片任务的追问因此是对上一轮文字结果的追问；未伪造原图上下文。
3. **视觉实现**：设计 §12 明确卡片视觉本仓库自建。使用 `OverlayPalette`/`OverlayMotion`/`OverlayViewUtils` 与原生 View，不复制 `theme/`、不引入 `DshGlyphs`。
4. **AskBar 复用方式**：读取了参考 `AskBarView` 的真实源码并保留其关键交互规则，但因依赖 pet 资源与 `AppStrings`，未复制文件；`AssistAskBar` 按本仓库包结构和资源重写。
5. **低版本 IME**：设计写的是 API 30 的 `WindowInsets.Type.ime()`；为覆盖 `minSdk 26`，增加 API 26–29 的旧式底部 inset 兜底。
6. **结构化动作**：卡片保留 `AssistResult.actions` 的消费位置，但 QA06 不渲染 ACTION_SHEET；地址/时间/电话动作与 Intent 跳转属于 QA10。
7. **卡片尺寸**：宽度严格为 safe area 两侧各留 16 dp；高度采用 260–560 dp 且不超过安全区域，设计未规定高度。
