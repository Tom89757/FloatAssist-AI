## 实现清单

### 平台层

- 从 `../dsh-Go-java/app/src/main/java/com/dshgojava/app/phone/a11y/` 复制悬浮球、截图、UI 树及其小依赖到 `com.dshgojava.assist.platform`。
- `OverlayBall` 保留真实构造器与交互：48dp 球、拖拽、贴边吸附、点击/长按停止、无障碍停止动作。
- `CaptureVisibility` 保留成对计数语义：截图前 `update(true)`，`finally` 中 `update(false)`。
- `ScreenShooter` 保留真实 `shoot(UiWindow, UiBox, List<ScreenElement>, List<UiBox>, long, boolean, boolean, boolean, BooleanSupplier)` 签名、API 30+ 截图、安全窗口识别、黑色图判定与 JPEG 编码。
- `TreeCapture` 保留真实四参数签名 `capture(AccessibilityService, UiBox, String, long)`，按窗口层级读取并释放无障碍节点。
- 复制 `LocalOcr` 边界，默认 `NoLocalOcr`，不会把“未安装 OCR”伪装成识别成功。
- `AssistA11yService` 是本仓库的最小无障碍端点：只挂接 `A11yBridge`，不执行后台操控；Manifest 与 `res/xml/assist_accessibility_service.xml` 声明 `canRetrieveWindowContent`、`canTakeScreenshot`。
- `A11yBridge` 进程内持有已连接的 `AccessibilityService`，提供连接判断、系统设置启用判断、屏幕边界与共享 `CaptureVisibility`。

### 取料接口与三类取料

| 类型 | 位置 | 行为 |
| --- | --- | --- |
| `AssistSource` | `assist/source` | `kind()`、`available()`、`gather()`，与设计文档 §5 一致 |
| `CaptureBundle` | `assist/source` | 文本、`PromptImage` 列表、只读 meta；文本与图片至少一项非空 |
| `ScreenSource` | `assist/source` | 先抓 UI 树；`needsVision=true` 或树文本少于 40 字符才截图；截图失败与安全窗口均显式失败 |
| `ClipSource` | `assist/source` | 后台读取剪贴板文本；空剪贴板、后台限制、超长内容均返回明确错误 |
| `ImageSource` | `assist/source` | 读取 UI 选中的 `Uri` 或请求上下文 `image_uri`；后台解码、EXIF 旋转、长边降至 1024 并重编码 JPEG |
| `PromptImage` | `assist/model` | QA03 依赖的不可变图片载荷；`byte[]` 构造与读取均防御性复制 |

`ScreenSource` 的补充规则：

- 截图隐藏在 `ScreenShooter` 内通过共享 `CaptureVisibility` 计数；截图结束无论成功或异常都会释放。
- 树文本按视觉顺序遍历，过滤密码、OTP、验证码字段；这些字段的矩形会作为截图遮罩输入。
- 截图错误若树文本仍可用且任务不需要视觉，返回文本并在 meta 记录 `screenshot_error`，不静默改道。
- 需要视觉但截图失败、树文本为空、安全窗口、Android 11 以下无法截图时均以 `CaptureException` 明确失败。
- `assist` 与 `PromptImage` 的字节都是本地内存副本；未写日志、历史或磁盘。

## 与设计文档的差异

1. **真实签名优先**：设计文档 §3 的 `TreeCapture.capture(...)` 省略了 `long budgetMs`，参考仓库真实方法为四参数。本实现采用真实四参数签名（预算 1500ms）。
2. **无障碍端点**：设计文档假设复用 `dsh-Go-java` 的 `PhoneA11yService`，但本独立仓库没有该服务，且其参考实现连带自动化驱动、控制条等大量无关依赖。本任务新增最小 `AssistA11yService` 并在 Manifest/XML 声明；`A11yBridge` 持有 `AccessibilityService` 而非 `PhoneA11yService`。该服务不做后台操控。
3. **ScreenShooter 可见性接缝**：复制时把参考仓库的 `ControlOverlay` 参数改为 `CaptureVisibility`，因为本仓库悬浮球由后续 `AssistOverlayService` 管理，不复制整套控制条。`shoot(...)` 方法签名与截图行为保持不变。
4. **平台依赖裁剪**：本任务只复制 `OverlayBall`、`ScreenShooter`、`TreeCapture`、`CaptureVisibility` 及其必需小依赖；`Actuator` 属于 QA10 动作跳转范围，`ScreenFormat`/`SensitiveWords` 未复制，改用本仓库纯逻辑 `ScreenTextExtractor`，避免拖动无关自动化依赖。
5. **图片入口**：`ImageSource` 已完成 URI 取料、解码和降采样，但本任务没有图片选择器/分享入口；UI 通过 `select(Uri)` 或请求上下文 `image_uri` 提供 URI。相册/分享接线属于后续 UI 任务，未实现“自动猜最近截图”，避免无权限时静默失败。
6. **悬浮球隐藏接线**：`CaptureVisibility` 已由截图流程正确成对更新，但 QA01 尚未创建悬浮球 UI；QA05 必须让 `AssistBall` 观察该可见性（或使用等价服务级隐藏）后才能完成“截图时不把球识别进去”的真机验收。
7. **降采样**：参考 `ScreenShooter` 先限制到 1300px；本仓库随后用 `ImageDownsampler` 按 EXIF 方向旋转并限制长边到 1024px，再编码 JPEG 85，符合设计 §8.3。
8. **剪贴板限制**：Android 10+ 后台读取可能被系统拒绝，且可能与“空剪贴板”返回相同结果；错误文案明确写“剪贴板为空或系统限制读取”，不假装成功。
