## 实现清单

### 前台服务

`app/src/main/java/com/dshgojava/assist/service/AssistOverlayService.java`

- 使用 `specialUse` 前台服务；Android 14 走 `startForeground(..., FOREGROUND_SERVICE_TYPE_SPECIAL_USE)`，低版本走普通 `startForeground(...)`。
- 建立“运行中”和“权限提示”两个通知渠道；运行通知带“关闭”动作，可停止悬浮球。
- 启动时先检查 `Settings.canDrawOverlays(this)`。无权限时：
  - Toast 明确提示“允许显示在其他应用上层”；
  - 发送可点击的权限通知，并尝试打开 `Settings.ACTION_MANAGE_OVERLAY_PERMISSION`；
  - 不创建球，直接停止服务，不假装工作。
- `OverlayBall` 的 `addView` 失败时同样 Toast + 通知明确说明，不静默停止。
- 提供 `show(Context)`、`hide(Context)`、`isRunning()`，供 QA09 设置页直接接入。
- 服务以 `TYPE_APPLICATION_OVERLAY` 显示窗口；仅在 Android 30+ 创建对应窗口上下文，26–29 使用服务上下文，保证无无障碍时剪贴板/图片入口仍可显示。
- 横竖屏变化时重新贴边，关闭已打开的菜单。
- 主线程只做视图与窗口操作；没有网络、截图、文件 IO。

### 悬浮球

`app/src/main/java/com/dshgojava/assist/ui/AssistBall.java`

- 包装 QA01 复制的 `OverlayBall`，保留其拖拽、速度判定、贴边、位置持久化能力。
- 点击球打开/关闭菜单；点击球时先关闭已打开菜单，避免再次弹出的闪烁。
- 拖拽贴边后继续使用参考实现的 `ballSide`/`ballY` 本机私有偏好保存位置。
- 静置 5 秒后视觉收缩到 32dp（按 32/48 缩放）并淡出到 0.35；触摸、拖拽、打开菜单时立即恢复。
- 长按回调当前显示“按住说话尚未开放”，为 QA11 显式占位，不静默无响应。
- 菜单窗口宽度上限 304dp，从球所在侧展开并钳制在安全区内；菜单内容切换后重新测量和定位。
- 菜单使用 `FLAG_NOT_FOCUSABLE | FLAG_NOT_TOUCH_MODAL | FLAG_WATCH_OUTSIDE_TOUCH`，点击外部关闭。

### 二级菜单

`app/src/main/java/com/dshgojava/assist/ui/AssistMenuView.java`

- 原生 View 实现两级菜单：一级为屏幕/网页/文本/图片四组，二级为对应任务。
- 任务标题按资源 ID 本地化映射，不直接回显 `QuickTask.title()` 的中文常量；未知任务才回退到注册表标题。
- 不可用任务灰显并显示具体原因：无障碍、模型、视觉、来源、暂未开放。
- 灰显任务仍可点击以进入对应修复路径：无障碍打开系统设置，模型/视觉提示设置页尚未接入，图片提示尚未选择/选择器未接入。
- 返回、关闭按钮可用；系统触摸外点击关闭；菜单内容超出屏幕高度时可滚动。

`app/src/main/java/com/dshgojava/assist/ui/AssistMenuModel.java`

- 纯 Java 菜单投影，不依赖 Android 类型，便于 JUnit 5 测试。
- 固定四组：`SCREEN`、`WEB`、`TEXT`（剪贴板）、`IMAGE`。
- `TaskGate` 为每个任务返回阻塞原因；`combine(...)` 聚合组状态：任一任务可用则组可用，否则按无障碍 → 模型 → 视觉 → 来源 → 未开放的优先级展示最可操作原因。
- P0 八条任务分别落入屏幕 4、文本 2、图片 2；网页组当前无 P1 任务，显示“暂未开放”。

## 与设计文档的差异

1. **窗口类型**：设计文档同时要求 `SYSTEM_ALERT_WINDOW` 和无障碍降级；参考 `OverlayBall` 固定使用 `TYPE_ACCESSIBILITY_OVERLAY`。若原样使用，未开无障碍时球无法显示，剪贴板/图片组也会被一起锁死。QA05 给 `OverlayBall` 增加窗口类型构造重载，默认行为仍为 `TYPE_ACCESSIBILITY_OVERLAY`，本应用使用 `TYPE_APPLICATION_OVERLAY`。
2. **参考类的可见性缺陷**：参考仓库 `OverlayBall.attach(...)` 在 `addView` 前把根视图设为 `GONE`，之后没有恢复可见；该类在参考仓库中未被调用，属于未触发缺陷。QA05 在本地复制件中改为 `addView` 成功后 `VISIBLE`。按照 AGENTS.md 硬规则，`../dsh-Go-java` 只读，未同时修改参考仓库；此差异在此登记。
3. **模型通道**：`AssistPrefs`/设置页属于 QA09，QA05 使用 `NullModelChannel`，因此菜单所有任务默认灰显“未连接，点此去连接”。点击后明确提示“设置页尚未接入”，不发起假调用；QA09/QA07 接入真实通道时替换服务内的通道与门控即可。
4. **网页组**：QA02 只注册 P0 八条任务，网页组暂无任务。菜单仍保留设计要求的四组，并显示“暂未开放”，未提前伪造网页任务。
5. **长按语音**：语音组属于 QA11。QA05 只保留长按回调并明确提示尚未开放，不把长按伪装成已完成能力。
6. **32dp 收纳**：采用球根视图视觉缩放实现（48dp × 32/48），窗口命中框仍为原 68dp 带内边距窗口；不改变 `OverlayBall` 的几何和拖拽算法。若真机验证发现命中区过大，再在 QA12 收尾调整为窗口尺寸变化。
