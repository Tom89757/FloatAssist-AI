## 实现清单

### 数据声明

以下类型均位于 `com.dshgojava.assist`，为不可变 record 或枚举，字段与 `docs/design/quick-assist.md` §5 对齐：

| 类型 | 关键字段/值 | 约束 |
| --- | --- | --- |
| `QuickTask` | `id`、`title`、`source`、`output`、`promptTemplate`、`needsVision` | `id`/`title` 非空白，枚举与模板非 null |
| `SourceKind` | `SCREEN`、`WEB`、`CLIP`、`IMAGE`、`VOICE`、`NONE` | 与设计文档完全一致 |
| `OutputKind` | `TEXT_CARD`、`COPY_TEXT`、`TRANSLATE_CARD`、`ACTION_SHEET` | 与设计文档完全一致 |
| `AssistRequest` | `task`、`context`、`userInput` | 上下文防御性复制；`userInput` 缺省为空串 |
| `AssistResult` | `stage`、`text`、`actions`、`error` | 动作列表不可变；空白错误归一为 null；提供状态工厂与 `terminal()` |
| `AssistAction` | `kind`、`label`、`value` | 支持导航、日程、拨号、复制；`value` 非空白 |
| `Stage` | `IDLE`、`GATHERING`、`THINKING`、`STREAMING`、`DONE`、`FAILED`、`CANCELLED` | 与设计文档完全一致 |

## 与设计文档的差异

1. 设计文档 §12 同时提到 `res/values/strings.xml` / `values-zh/strings.xml` 的设置入口文案；QA00 将所有快捷助手文案集中放在 `quick_assist_strings.xml`（含设置与权限文案），未另建通用 `strings.xml`。设置页及其入口属于 QA09，届时如需独立入口文案再补。
2. 设计文档只规定 `AssistAction` 为“结构化动作”，未固定字段。本实现采用 `Kind + label + value`，其中 `Kind` 为 `NAVIGATE/CALENDAR/DIAL/COPY`，便于 QA10 直接映射 Intent。
3. `AssistOverlayService` 当前只保留声明与停止逻辑，尚未启动前台通知。该行为是 QA00 骨架边界，完整生命周期在 QA05 实现；当前未向用户暴露入口，不构成静默降级。
4. QA00 数据声明没有可直接复制的参考仓库同名类，均为按设计文档自建；因此 `assist/platform/` 在本任务中保持为空，QA01 再按真实签名复制平台能力。
