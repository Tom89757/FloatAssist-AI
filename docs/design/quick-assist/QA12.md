## 与设计文档的差异

1. **无障碍服务**：设计 §3/§10 假设复用参考仓库的 `PhoneA11yService` 且不新增服务；本仓库是独立应用，改为最小 `AssistA11yService`，只持有无障碍连接，不执行后台操控。
2. **StateStore 包名**：设计 §5 的 `com.dshgojava.app.state.StateStore` 是旧仓库包名；实现按 §12 自建 `com.dshgojava.assist.StateStore`，保持观察者与不可变快照语义。
3. **模型通道集合**：只实现 `DirectApiModelChannel` + `NullModelChannel`，未实现设计 §4 提到的 `SessionModelChannel`；直连方式符合 §8.7 的无状态请求要求。
4. **P1 任务子集**：设计 §7 列出六个 P1 方向，本批任务只覆盖 `screen.actions` 与 `voice.transcribe`。网页、二维码、PDF 摘要不在 QA00–QA12 范围内，网页组菜单明确显示“即将支持”而非假装可执行。
5. **真实签名优先**：`TreeCapture.capture` 采用参考仓库真实四参数签名（包含 timeout/budget）；设计 §3 的摘要省略了该参数，已在 QA01 记录。
6. **Manifest 扩展**：除设计 §10 的四个权限外，直连模型需要网络权限，语音需要录音权限；这些是实际实现所需，不是静默能力扩张。
7. **验证方式**：Gradle 无法在沙箱启动 daemon，本次使用 Android SDK `javac`、JUnit Platform 和 XML/BOM 静态检查等价验证；这不等于 Gradle 构建或真机验收已通过。
